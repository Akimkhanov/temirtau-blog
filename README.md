# Мой Темиртау

Простой личный блог о городе Темиртау на чистом HTML, CSS и JavaScript.

## Что включено

- Главная hero-секция
- Раздел о городе
- Блок с местами для прогулок
- Галерея изображений
- Блог-статьи
- Адаптивная навигация для мобильных устройств

## Как запустить

Откройте файл `index.html` в браузере или используйте локальный сервер.

Пример:

```bash
python -m http.server 8000
```

После этого откройте: http://localhost:8000

## Структура проекта

- `index.html` — основная разметка сайта
- `styles.css` — стили и адаптивность
- `script.js` — небольшая логика для меню
